# Tugas Pertemuan 4 — MaterialApp

Tugas mata kuliah **KB1185 Aplikasi Mobile** (Flutter), Pertemuan 4.
Dosen: I Ketut Gunawan, S.KOM, M.T.I — Institut Teknologi & Bisnis Bina Sarana Global.

## Isi

Aplikasi Flutter sederhana untuk mempelajari `MaterialApp` sebagai
konfigurasi utama aplikasi: hubungan `main()`, `runApp()`, `MaterialApp`,
dan `Scaffold`, serta properti penting seperti `title`, `theme`,
`darkTheme`, `themeMode`, `debugShowCheckedModeBanner`, dan `home`.
